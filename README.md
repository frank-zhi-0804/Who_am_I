# 来处 · 家族溯源交互原型

预览地址：http://127.0.0.1:4173

在此目录运行 `node serve.cjs` 后打开上述地址。不要直接双击 index.html，地图的后台线程需要 HTTP 环境。

体验：直接提问，或点击三个阮氏示例问题。选择字辈后继续问迁徙线索、堂号或怎样向家人了解信息；点击线索卡片、地图地点或下方背景线索可飞到当地。路线在用户选择展开迁徙线索后才出现，“重新开始”会清空本次对话并隐藏路线。右上角山形按钮可开启联网地形；普通底图与高程数据需要互联网。省级轮廓和地图库已随原型保存，网络不可用时仍可查看示意地图。

第一阶段已改为固定对话演示，支持自由输入但仅预置阮氏回答，不会把其他姓氏强行匹配到示例。

本版本不做真实网络检索，不确认个人与任何支系的关系，不持久化姓名。全部历史线索来自本次对话提供的材料，尚未核查原始文献；陈留文化背景没有连接到迁徙路线。虚线只是候选迁徙示意，不代表真实道路。

基础地理数据：https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json
地图：MapLibre GL JS 5.6.0；底图：OpenStreetMap；可选高程：AWS Terrain Tiles。

已验证：后台浏览器中的示例查询、支系切换、地图加载与飞行、历史内容切换、手机宽度；有效及无效工具输入也已检查。实际浏览器原生 WebMCP 环境不可用，仅通过模拟注册接口验证。
