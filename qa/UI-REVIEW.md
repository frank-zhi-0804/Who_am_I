## 验收路径

1. 桌面打开首页，确认示例模式、四处背景地点、路线默认隐藏；点击示例 → 字辈 → 迁徙路线 → 乐平，检查地点卡、飞行和未被遮挡的 marker。
2. 点击重新选择字辈，确认旧路线立即隐藏；切到阳新分支，确认支系变化与路线重置。
3. 实际输入空格、否定姓氏、未知字辈、另一个姓氏和 HTML 字符串，确认输入校验、保留不确定性、清理候选和安全文本显示。
4. 切真实溯源，确认示例节点与对话清空；未配置服务时发送问题，确认明确提示未查询、没有请求真实 API、没有假结果。
5. 手机打开对话页，确认首屏可操作输入框和发送按钮；字辈追问保持对话视图，明确展开路线才打开地图；点击地图地点，确认 marker 在视口内且未被地点详情挡住。
6. 点击继续问这个地方，确认返回对话、填写草稿并聚焦；往返地图和对话，确认对话不丢失。
7. 本地模拟研究中、服务失败、重试、成功，确认发送按钮与进度状态、忙时 Enter 保留草稿且无重复请求、重置后迟到结果被丢弃。
8. 本地模拟含来源的线索，确认正文 [S1] 就近链接、来源卡、过滤无来源地图点与路线、安全 URL、地图更新提示。
9. 连续两次本地模拟回答替换地图后，点击前一轮卡片，确认仍可回看其地点且没有未知地点异常。
